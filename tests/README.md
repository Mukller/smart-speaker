# Проверки

Два слоя. Первый быстрый и обязательный, второй бьёт по живому сайту.

## Быстрые (без браузера, без сети)

```bash
python3 tests/check_routes.py
```

Проверяет, что интерфейс и тесты говорят с сервером по одним путям. Живой
пример, зачем это нужно: интерфейс перевели на единый префикс
`/kolonka/api/`, а три теста продолжали считать запросы по старым путям
`/kolonka/tts`, `/kolonka/stt`, `/kolonka/timerwav`. Наборы падали, хотя
приложение было живо: `curl` отдавал 200 за 165 мс. Три теста показывали
провал, и это выглядело как регрессия.

С `--live` дополнительно спрашивает каждый путь, который дёргает интерфейс:

```bash
python3 tests/check_routes.py --live
```

## Браузерные (нужны Playwright и сеть до прода)

```bash
pip install playwright
python3 -m playwright install chromium
python3 tests/run_all.py                 # все наборы
python3 tests/run_all.py alarm search    # выборочно
```

Прогрев внутри: после перезапуска контейнера первая модель vosk грузится
лениво, и без прогрева проверки получают таймаут на живом приложении.
Отключается `--no-warmup`.

Код возврата ненулевой, если хоть один набор дал провалы, поэтому раннер
можно ставить в cron или в локальный pre-push.

Куда смотреть: `tests/out/*_report.txt` и `tests/out/*.png`. Путь
переопределяется переменной `JANE_OUT`. Сайт - через `JANE_URL`
(по умолчанию прод).

## Наборы

| файл | что проверяет |
|---|---|
| `e2e_win2.py` | основной UI, контраст, лента сообщений |
| `e2e_voice.py` | озвучка ответов, кнопка «Озвучить ответ» |
| `e2e_stt.py` | распознавание речи, отправка аудио |
| `e2e_plugins.py` | список плагинов, команды, переключатели |
| `e2e_alarm.py` | постановка, отсчёт, отмена, звонок, пропущенный звонок |
| `e2e_hot.py` | постоянное слушание с будильниковым словом |
| `e2e_search.py` | поиск музыки, оба источника, проигрывание |
| `e2e_player.py` | команды плеера, громкость, переключение треков |

## Известная хрупкость

Все восемь наборов подряд на одной машине дают нестабильные тайминги: СТТ
грузит vosk на CPU, будильник ждёт точного момента звонка. Если в общем
прогоне падает то, что одиночно зелёное - гоняйте сомнительный набор
отдельно и смотрите отчёт, а не на число вслепую.
