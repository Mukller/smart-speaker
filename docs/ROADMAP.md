# ROADMAP — от идеи до колонки

Каждый этап — законченный шаг, который можно проверить руками.

## M0. Прототип на ПК (начальная точка)

- Запустить `vendor/irene-va/runva_vosk.py` на ПК (ноутбук Ryzen 7 5800U, CPU).
- Скачана русская модель Vosk small (см. `vendor/irene-va/model/README.md`).
- TTS: Silero v3 (плагин `plugin_tts_silero_v3.py`, требует torch CPU).
- Имя ассистента: «дженет» (опция `voiceAssNames`).
- Проверить команды: «дженет привет», «дженет таймер три минуты», «дженет который час»,
  «дженет погода» (OpenWeatherMap ключ — в настройках, не в гите).

Критерий: диалог по голосу без клавиатуры, латентность ответа < 3 с.

## M1. Русский голос — довести до «как у настоящей колонки»

- Сравнить на живых фразах: Silero v3/v4 vs Piper ru (irina/denis) vs RHVoice vs edge-tts.
- Нормализация текста через runorm (плагин `plugin_normalizer_runorm.py`) — числа,
  единицы, сокращения озвучиваются корректно.
- Кэшировать озвучку (`useTTSCache`).

Критерий: выбран один основной TTS, прослушаны тестовые фразы, выключен console-TTS.

## M2. Wake word «дженет»

- Вариант А (уже работает): Vosk-грамматика по имени (опция `voiceAssNames`) —
  базовый уровень, работает, но жрёт CPU на постоянный полный STT.
- Вариант Б: Porcupine (есть русская поддержка, бесплатный тариф для личного использования).
- Вариант В: openWakeWord / mycroft-precise с тренировкой своего слова «дженет».
- Критерий: колонка спит < 5% CPU, срабатывает на «дженет», игнорирует фоновый звук.

## M3. Скиллы, которые реально нужны дома

- Таймеры/будильники (уже есть в Irene).
- Погода (уже есть, выбрать источник).
- Медиа: управление MPC-HC / плеером на сервере (mpcapi уже в вендоре).
- **Умный дом**: новый плагин для Home Assistant REST/WebSocket
  (свет, сценарии, датчики) — главный новый код проекта.
- Напоминания/списки покупок (синхронизация в Obsidian/телефон — есть стек Syncthing).

Критерий: 10+ полезных команд, которыми реально пользуешься неделями.

## M4. LLM-болталка на русском

- База: плагин `plugin_boltalka_vsegpt.py` (OpenAI-совместимый endpoint).
- Endpoint'ы: VseGPT (просто), OpenRouter (есть ключ), либо локальная Ollama
  (модели с русским: qwen2.5, gemma) на домашнем сервере 192.168.0.36.
- Контекст диалога через механизм контекстов Irene (`contextDefaultDuration`).

Критерий: свободный разговор по-русски без интернета (Ollama) — или с ним (VseGPT).

## M5. Железо

См. [HARDWARE.md](HARDWARE.md): Raspberry Pi 4/5 или mini-PC, ReSpeaker/USB-микрофон,
MAX98357A + динамик, корпус с 3D-принтера (CoreXY под рукой).

Критерий: работает автономно, как колонка, а не как ПК с колонками.

## M6. Серверная часть

- Docker на домашнем сервере: `vosk_asr_server.py` (централизованный ASR),
  при необходимости — общий TTS-сервис (Silero-TTS-Service / openedai-speech).
- Клиенты-колонки становятся тонкими: микрофон + динамики + wake word.

Критерий: две колонки в разных комнатах работают от одного сервера.

## M7. Полировка

- AEC/эхоподавление (не перебивает сам себя), VAD, подавление шума.
- Подавление ложных срабатываний (лог + статистика).
- Автозапуск как сервис (systemd / автологин), watchdog.
- Обновления через git pull на сервере.

## Принципы

- Каждый этап коммитится отдельно, ветки через PR.
- Секреты (API-ключи, токены HA) — только в локальных опциях/.env, никогда в гит.
- Заимствуем готовое с атрибуцией (см. NOTICE), не пишем своё там, где есть чужое проверенное.
