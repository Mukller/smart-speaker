## 1. thirdreality / voice-music-assistant — ОСОБОЕ ВНИМАНИЕ
**Звёзды:** 19 | **Лицензия:** Apache-2.0 | **Язык:** C++ / Linux / buildroot

Что это: полноценная умная колонка (динамик + микрофон) с двумя режимами:
- **Voice** — C++ rewrite проекта [OHF-Voice/linux-voice-assistant], работает как ESPHome native API satellite для Home Assistant Voice Assistant. Поддерживает локальный STT (Wyoming-piper / faster-whisper) или облачный HA Cloud.
- **Music** — потоковый протокол [Sendspin](https://www.sendspin-audio.com/), интегрируется с [Music Assistant](https://www.music-assistant.io/). Многокомнатная музыка с Apple HomePod / Sonos через AirPlay.

Структура репо (из README / webfetch):
- `buildroot/` + `Dockerfile` — сборка образа (Ubuntu 20.04, Docker или native).
- `script/`, `sources/`, `tools/Aml_Burn_Tool` — прошивка через USB или ADB (TCP 5555, без авторизации — важная грабля безопасности для нашей адаптации).
- `doc/` — документация по настройке, кнопкам (нажатие одинарное/двойное/тройное), Wi-Fi, SSH (`hello3r`).
- **Железо:** Amlogic-чип (Aml Burn Tool для прошивки), USB-микрофон или встроенный массив, усилитель звука, кнопка управления.
- **Debug:** Serial 115200, ADB (USB и TCP :5555), SSH (`root`/`hello3r`).
- **Для работы нужен Home Assistant** (ESPHome satellite). Голосовая команда: «OK Nabu» (wake-word в firmware).

Что брать для нашего проекта:
- **Архитектура:** разделение на Voice + Music — то, что нужно для полноценной колонки.
- **Интеграция с HA:** ESPHome native API — готовый способ подключить ассистента к HA Voice Assistant. Мы уже планируем HA-плагин в M3; этот репозиторий — готовая реализация satellite-стороны.
- **Wake word + кнопки:** обработка событий кнопки (одинарное/двойное/тройное нажатие) — можно взять в ядро.
- **Sendspin / Music Assistant:** если добавлять музыку в колонку (M7) — готовый протокол и интеграция.
- **Безопасность:** в репо ADB TCP слушает на 0.0.0.0:5555 без аутентификации. При адаптации под наш сервер **обязательно отключать** или ограничивать (`ADB_TCP_PORT=` в `/etc/default/adbd`).
- **Не брать:** прошивку под Amlogic, buildroot под конкретный чип (если делаем на RPi / x86) — архитектура сборки берётся как пример, не код прошивки.
- **Код основной части:** `linux-voice-assistant-cpp` (C++) — лицензия репозитория Apache-2.0, но основной C++-код можно брать с сохранением авторства. Для нашего Python-ядра (Irene) это скорее архитектурный образец, чем прямое копирование.

**Вывод для проекта:** это ближайший к нашей цели готовый open-source speaker. Мы не копируем всю прошивку под Amlogic, но берём идеи: ESPHome satellite, Wyoming-пайплайн (Piper + faster-whisper), Sendspin для музыки, кнопки, безопасность ADB.

## 2. lovelyterry / SmartSpeaker
**Описание (из поиска):** Smart speaker DIY с поддержкой Linux / FreeRTOS, чип stm32f407vet6, кодек wm8978, ESP8266 для Wi-Fi, SD-карта.
**Анализ:** аппаратная платформа на STM32 + ESP8266, не на RPi. Наш проект ориентирован на RPi / x86 / ноутбук (см. HARDWARE.md). Код под FreeRTOS — не совместим с нашим Python-ядром. Но архитектура (микрофон → кодек → ESP8266 → Wi-Fi) полезна для понимания железа на низком уровне. **Не брать код, только идеи сборки микрофон-кодек-сеть.**

## Особое внимание: `thirdreality/voice-music-assistant`

Это **самый близкий готовый open-source speaker** к нашей цели:
- **Аппаратная платформа:** Linux / buildroot (Amlogic), не ESP32. Значит — можно адаптировать под RPi / x86 без полной смены архитектуры (buildroot можно заменить на Docker или нативную сборку).
- **Voice:** использует [OHF-Voice/linux-voice-assistant](https://github.com/OHF-Voice/linux-voice-assistant) (C++) в виде ESPHome native satellite. Для нашего проекта это значит: мы можем использовать ESPHome как промежуточный слой для HA-интеграции, но основной код ассистента остаётся Python (Irene) для гибкости плагинов.
- **Music:** [Sendspin](https://www.sendspin-audio.com/) — лёгкий протокол потоковой передачи. Для нашей колонки это означает, что музыка не требует сложных DLNA/UPnP-серверов; можно использовать Sendspin для воспроизведения с сервера или Music Assistant.
- **Актуальные грабли из репо:**
  - ADB TCP (`5555`) слушает на `0.0.0.0` без авторизации — при адаптации отключать или ограничивать через `ADB_TCP_PORT=`.
  - SSH (`hello3r`) — пароль известен; при развёртывании менять.
  - USB-кабель для прошивки через Aml Burn Tool — это не для RPi, но для нашей M5 (RPi) не нужно.
- **Что взять в код / конфигурацию:**
  - Схему кнопок (одиночный/двойной/тройной клик) → `vacore.py` / новый плагин событий кнопки.
  - Концепцию «Voice + Music» → наш M7 (добавить Music Assistant в колонку).
  - ESPHome native API для HA Voice Assistant → наш M3 (HA-плагин для Irene или ESPHome-сателлит как отдельный клиент).
  - Документацию по настройке (Wi-Fi через BLE, настройка в HA) → наши `docs/HARDWARE.md` и `docs/ROADMAP.md`.
- **Что НЕ брать:** C++ firmware под Amlogic (мы не собираемся делать свой чип), buildroot-пайплайн (слишком специфично для этого чипа), ADB без авторизации (исправить).

## Что нам нужно, чтобы полностью собрать умную колонку (синтез)

На основе анализа всех репо + нашей базы Irene + требований Антона («русский язык», «максимум заимствований»):

### 1. Программное ядро (уже в репо)
- **STT:** Vosk small ru (`vendor/irene-va/model` — модель скачать) — работает на CPU.
- **TTS:** Silero v3/v4 (`plugins/` в Irene) — основной голос; добавить сравнение с Piper ru в `STACK.md`.
- **Понимание команд:** `vacore.py` + `lingua_franca/ru` — уже работает. Добавить `voiceAssNames` = «дженет».
- **Wake word:** Vosk-грамматика (уже работает в Irene `core.py`) → для M2: заменить/дополнить Porcupine или openWakeWord для «дженет».
- **LLM-болталка:** `plugin_boltalka_vsegpt.py` (OpenAI-совместимый endpoint) — M4. Добавить Ollama-опцию для полного оффлайна на сервере (`192.168.0.36`).

### 2. Умный дом / интеграция (M3)
- **Новый плагин для Home Assistant:** REST или WebSocket (ESPHome или прямой API). Использовать опыт `thirdreality/voice-music-assistant` (ESPHome native satellite) и `AlexxIT/StreamAssist`.
- **Что заимствовать:** архитектуру satellite из `voice-music-assistant`, идеи интеграции из `StreamAssist`, документацию ESPHome из репо `OHF-Voice`.

### 3. Музыка (M7)
- **Sendspin** (из `voice-music-assistant`) — лёгкий протокол. Добавить плагин в Irene или отдельный сервис в Docker.
- **Music Assistant** как бэкенд — готовая интеграция в репо `voice-music-assistant` (через Add-on).
- **Не писать свой DLNA-сервер** — использовать готовый Sendspin или Music Assistant.

### 4. Железо / корпус (M5)
- **RPi 4/5 или mini-PC** (наш сервер `192.168.0.36` для бэкенда M6, колонка — тонкий клиент или автономная).
- **Микрофон:** ReSpeaker 2-Mics или хороший USB-микрофон (см. `voice-music-assistant` — USB-кабель для прошивки и настройки).
- **Динамик + усилитель:** MAX98357A (I2S) или готовая USB-колонка с усилителем.
- **Корпус:** 3D-печать на CoreXY (у Антона есть), дизайн по `voice-music-assistant` (перфорированная передняя панель) или `nevo`.
- **Кнопки:** одинарное / двойное / тройное нажатие — взять схему из `voice-music-assistant` (документация в `doc/` репо).

### 5. Безопасность / сеть (M6)
- **ADB:** отключить TCP (`ADB_TCP_PORT=` в `/etc/default/adbd`) или слушать только на localhost.
- **SSH:** сменить пароль (`hello3r` → свой) или использовать ключи.
- **API-ключи:** никогда не коммитить (`.env`, опции в `core.py`). В репо только заглушки (`plugin_weatherowm.py` — `apiKey: ""`).
- **Docker:** использовать для ASR-сервера (`vosk_asr_server.py`) и LLM (`Ollama`), чтобы обновления были в одном месте.

### 6. Дополнения / M8 (после базовой версии)
- **Идентификация говорящего:** `EuleMitKeule/speaker-recognition` — добавить профиль «Антон / гость» для персонализации ответов.
- **Стерео / двойной микрофон:** `sapperxl/Dual-Speaker-Mic-Voice-Assistant` — улучшить AEC и захват с двух точек (AEC = подавление эха при воспроизведении через динамик).
- **Приватный режим:** `VGCH/alpha-private-speaker-connector` — режим «наушники» или «не слушать».
- **ESP32-клиент:** `MrBuddyCasino/ESP32_Alexa` или `MarcoFre/ESP32-S3-AI-Smart-Speaker` — если нужна очень дешёвая сателлит-колонка в каждой комнате.
