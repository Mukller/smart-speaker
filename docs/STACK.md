# STACK — выбор компонентов для русского голоса

## STT (распознавание речи, русский)

| Вариант | Лицензия | Плюсы | Минусы | Вердикт |
|---|---|---|---|---|
| **Vosk small ru** (alphacep/vosk-api) | Apache-2.0 | Оффлайн, ~50 МБ, CPU в реальном времени, уже в Irene | WER ~12–22% на бытовых фразах | **Основной (M0)** |
| Vosk big ru | Apache-2.0 | Точнее | ~1.9 ГБ, тяжелее | Для серверного ASR (M6) |
| faster-whisper (large-v3-turbo) | MIT | Лучшее качество, есть на сервере в voice-notes | Латентность выше, для realtime нужен GPU | Серверный вариант M6 |
| RealtimeSTT (KoljaB) | MIT | VAD+wake-word обёртка над whisper | Тяжелее Vosk | Вдохновение для M2 |

Модель уже протестирована автором Irene: WER 11.79 (golos_crowd), 21.34 (farfield) —
см. `vendor/irene-va/model/README.md`.

## TTS (озвучка, русский)

| Вариант | Лицензия | Плюсы | Минусы | Вердикт |
|---|---|---|---|---|
| **Silero TTS v3/v4** (snakers4/silero-models) | см. репо модели (NOTICE) | Нейро-качество, 5+ русских голосов, быстрый на CPU | Нужен torch (v3); лицензию моделей проверить перед коммерческим использованием | **Основной** |
| Piper (rhasspy/piper) | MIT | Мегалёгкий (заточен под RPi), ru_RU голоса (irina, denis, dmitri, ruslan) | Качество ниже Silero на сложных фразах | Основной для RPi |
| RHVoice | LGPL | Очень легковесный, старый но живой | Звучит «синтетично» | Запасной (плагин есть в Irene `plugins_inactive`) |
| edge-tts (rany2) | см. репо | Голоса Microsoft бесплатно, по-русски отлично | Только онлайн, неофициальный | Резерв при работающем интернете |
| OpenAI-совместимый TTS (VseGPT) | проприетарный сервис | Голоса OpenAI по-русски | Онлайн, платно | Опция через Irene |

В Irene плагины уже есть: `plugin_tts_silero_v3.py`, `plugin_tts_silero_v4.py`,
`plugin_tts_pyttsx.py`, `plugin_tts_vosk.py`, `plugin_tts_elevenlabs.py`.

## Wake word («дженет»)

| Вариант | Лицензия | Плюсы | Минусы |
|---|---|---|---|
| Vosk-грамматика по имени (Irene `voiceAssNames`) | Apache-2.0 | Уже работает, ноль доп. кода | Постоянный полный STT = CPU |
| Porcupine (Picovoice) | Apache-2.0 (SDK), модели по free-tier ключу | Готовые + кастомные RU слова, дешёвый CPU | Модели проприетарные, нужна регистрация ключа |
| openWakeWord | Apache-2.0 | Тренируем своё слово, открыт | Нужна тренировка (кустом «дженет») |
| mycroft-precise | Apache-2.0 | Проверенный, много гайдов | Проект Mycroft в поддержке OVOS |

План: M2 стартует с А (уже работает), мигрирует на Porcupine/openWakeWord.

## Понимание команд

- **Ядро Irene**: команды через плагины + контексты, нечёткий матчинг (`fuzzyThreshold`).
- `lingua_franca` (ru): числа, даты, время («таймер на полтора часа» → 5400 с).
- `num_to_text_ru.py` + runorm: обратная конвертация и нормализация для TTS.

## Умный дом

- Home Assistant REST/WebSocket — новый плагин для Irene (M3).
- Готовое для вдохновения: StreamAssist (AlexxIT), voice-satellite-card, Rhasspy-интеграции.

## Чего НЕ делаем

- Не изобретаем свой STT/TTS-движок.
- Не тянем облако как обязательное условие (оффлайн-фёрст).
- Не коммитим модели и ключи в репозиторий.
