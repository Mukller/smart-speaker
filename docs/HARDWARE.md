# HARDWARE — варианты железа

## Вариант 1: Прототип на существующем ПК (M0)

- Ноутбук Ryzen 7 5800U (8C/16T) — CPU тянет Vosk small + Silero CPU.
- Любой USB-микрофон и любой динамик/наушники.
- Цель: отработать софт, не тратя ни рубля.

## Вариант 2: Целевая колонка на Raspberry Pi (M5)

| Компонент | Вариант | Заметки |
|---|---|---|
| С compute | Raspberry Pi 4 2GB / Pi 5 / любой mini-PC x86 | Vosk small + Silero v3 идут на CPU Pi 4 |
| Микрофон | USB-микрофон / ReSpeaker 2-Mics pHAT | ReSpeaker даёт лучше захват с расстояния |
| Звук | MAX98357A (I2S) + динамик 2–3 Вт | Классическая связка DIY-колонок |
| Питание | БП 5В 3А | |
| Корпус | 3D-печать на CoreXY | Тканевая/перфорированная передняя панель |

Ориентир архитектуры — репозитории из docs/SIMILAR-PROJECTS.md
(open-voicebox-pi, nexo, ai-smart-speaker: RPi + усилитель + микрофон-массив).

## Вариант 3: Серверный бэкенд (M6)

- Домашний сервер 192.168.0.36 (Haswell Xeon E3) — Docker:vosk_asr_server,
  Ollama для LLM, общий TTS-сервис.
- Колонка становится тонким клиентом: wake word локально, STT/TTS/LLM по LAN.
- Плюс: одна дорогая модель на все колонки, обновления в одном месте.

## Вариант 4: Перепрофилирование

- Старая USB-колонка/ boombox: добавить RPi внутрь корпуса.
- Планшет/телефон: webapi_client из Irene (микрофон через браузер).

## Что купить в первую очередь (когда прототип на ПК покажет себя)

1. ReSpeaker 2-Mics HAT или хороший USB-микрофон (~15–30 $).
2. MAX98357A + динамик (~10 $).
3. Raspberry Pi 4 (если нет) или донор mini-PC.

Не покупать до прохождения M0–M2: сначала убедиться, что программная часть
даёт опыт, ради которого колонку вообще хочется.
